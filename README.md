# Batman Motion

Landing page temática do Batman com animações de scroll, construída com React, TypeScript, Vite e GSAP.

## Tecnologias

- React 19 + TypeScript
- Vite
- GSAP (ScrollTrigger)
- Oxlint

## Como rodar

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — inicia o servidor de desenvolvimento
- `npm run build` — build de produção
- `npm run preview` — pré-visualiza o build
- `npm run lint` — roda o linter
