# Batman Motion

Pagina imersiva inspirada no universo do Batman, desenvolvida com foco em uma experiência visual cinematográfica. O projeto utiliza animações acionadas pelo scroll para revelar textos, blocos e elementos da interface de forma fluida durante a navegação.

Confira a landing page funcionando: [batman-motion.vercel.app](https://batman-motion.vercel.app/)


## Tecnologias

- React com TypeScript
- Vite
- GSAP e ScrollTrigger
- Oxlint

## Como rodar

Antes de começar, tenha o [Node.js](https://nodejs.org/) instalado em sua máquina.

```bash
npm install
npm run dev
```

Depois, acesse o endereço exibido no terminal para visualizar o projeto no navegador.

## Scripts

- `npm run dev` — inicia o servidor de desenvolvimento
- `npm run build` — gera o build otimizado para produção
- `npm run preview` — executa uma pré-visualização do build
- `npm run lint` — verifica a qualidade e a padronização do código


## Build de produção

Para gerar a versão final do projeto, execute:

```bash
npm run build
```

Os arquivos otimizados serão criados na pasta `dist`.
